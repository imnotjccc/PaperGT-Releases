# PaperGT Releases

PaperGT 的官方公开下载与自动更新仓库。这里仅保存由私有源码仓库 GitHub Actions 构建并通过启动测试的安装包和更新元数据。

- [下载最新版](https://github.com/imnotjccc/PaperGT-Releases/releases/latest)
- Windows 长期使用推荐 `PaperGT-Setup-*-Windows-x64.exe`，安装版支持应用内更新。
- Portable 版需要手动下载新版本。
- 当前安装包尚未代码签名，Windows SmartScreen 或 macOS Gatekeeper 可能显示未知发布者提示。

论文、笔记、阅读状态和 API Key 均保存在用户自己的电脑上；应用更新不会删除这些数据。
